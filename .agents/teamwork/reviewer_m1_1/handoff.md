   - Based on *Observation 4*, the regex safely extracts SHA-256 digests across all intended release note conventions.

   - If the user denies the UAC prompt, `Process.Start` throws `Win32Exception` prior to `Application.Current.Shutdown()`, keeping the application alive and logging a warning.

## 3. Caveats

1. **Relaunch Process Elevation Context**:
   - In `apply.ps1`, `Start-Process -FilePath $exe1` is invoked from within an elevated PowerShell script (`Verb = "runas"`). While this relaunches the updated app, the child process initially inherits elevated privileges. The fallback `explorer.exe "shell:AppsFolder\$($pkg.PackageFamilyName)!App"` launches de-elevated under interactive user token. This is an informational observation that does not impair update functionality.
2. **GitHub API Rate Limits**:
   - Unauthenticated GitHub API calls are subject to IP rate limits (60/hour). In the event of HTTP 403, the service handles `HttpRequestException` gracefully without crashing.
